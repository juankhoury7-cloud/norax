# Norax

Tu guía en CEDEARs: señales de compra y venta para CEDEARs a semanas, con seguimiento de tu cartera en pesos.

- App: https://juankhoury7-cloud.github.io/norax/
- Precios: Twelve Data (cada usuario usa su propia clave gratuita) y dólar CCL de dolarapi.com.
- Las claves y la cartera se guardan en el navegador de cada usuario, no en este repositorio.

Herramienta de análisis técnico. No es asesoramiento financiero.
